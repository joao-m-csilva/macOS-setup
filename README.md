# MacOS Setup

## Script criado para automatizar o setup de um novo computador com MacOS para desenvolvimento de software.

## Desenvolvimento

- Homebrew
- Git
- Node (nvm)
- Docker
- PostgreSQL
- Dbeaver
- VsCode
- AWS CLI

## Instalação

Para iniciar a instalação base para o novo macOS execute `./scripts/install.sh`
